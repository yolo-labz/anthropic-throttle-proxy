# Identity and state

Product: **Throttler**. Distribution: `throttler-gateway`, version `0.1.0`.
Canonical package: `throttler_gateway`. Gateway and ingress are process roles,
not provider names. Canonical entry modules expose the existing runtime's
`main` functions; no new runtime, configuration or storage entity is introduced.

Legacy package, state and wire identities remain compatibility contracts.
Provider adapter, protocol and account identities remain observed provider facts.
