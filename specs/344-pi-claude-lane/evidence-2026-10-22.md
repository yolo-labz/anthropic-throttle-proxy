## 2. DEFECT (FIXED 22/10/2026) — injection was not scoped to the sentinel lane

> **Status: fixed in the same working tree.** `_inject_lane_system_prompt` now
> returns the body untouched unless the request itself rode the sentinel lane:
> `x-api-key` equals the sentinel AND no `Authorization` header is present —
> mirroring the strip in `_route_account_if_enabled`. Claude Code's own OAuth
> traffic is therefore forwarded byte-identical and its `cache_control`
> breakpoints survive. Contract pinned by
> `tests/test_lane_system_injection.py` (5 passed): sentinel+pi → marker-only
> system with the prompt folded into the first user message; Authorization
> bearer → byte-identical; foreign `x-api-key` → untouched; already-marked
> body → not double-folded.

The original uncommitted version gated only on the process-wide env var:

`_shrink_forward_body` (`proxy.py:4913`) calls the injector for **every** POST
body on the forward path. The only guard is `config.LOCAL_API_KEY_SENTINEL`
being non-empty — a process-wide env var. It never checks whether *this*
request's auth was sentinel-rewritten, contradicting its own docstring
("Only applies when the sentinel routing rewrote auth").

Blast radius: Claude Code points at the ingress `:8760`
(`ANTHROPIC_BASE_URL`, verified on PIDs 426768 / 476196 / 476203), whose
`default_lane` is `:8765`. So all Claude Code traffic on this host is rewritten.

Reproduction (offline, no quota):

```
$ THROTTLE_LOCAL_API_KEY=local-lane-via-8765 .venv/bin/python …
sentinel set: 'local-lane-via-8765'
system blocks after: 1
cache_control survived: False
first user msg: "[system preamble]\nYou are Claude Code, …\n\n<big CC system prompt>…
```

Consequences for genuine Claude Code requests:

1. **`cache_control` is destroyed** → prompt caching is lost on every request
   through `:8765`. This is the expensive one: it inflates billed input on
   every turn of every pane, which works directly against the stated motive
   for stripping the blocks (avoiding "extra usage").
2. `system` collapses from 2 blocks to 1.
3. The marker is duplicated — once as the new `system`, once inside the
   `[system preamble]` fold.

## 5. Open decision (owner: Pedro)

The sentinel path works by presenting the Claude Code identity string so a
subscription (OAuth) credential is accepted for a third-party client, and by
stripping the other system blocks so the gate does not meter them. That is
circumvention of Anthropic's entitlement check, so this seat did not extend,
scope, or commit it.

Supported alternative: an Anthropic **API key** on the pi provider. api-key
bearers are exempt from the gate by construction
(`_is_entitlement_refusal_attempt` narrows to non-`api-key` bearers), and with
`explicit_api_key` true (`proxy.py:1826`) account routing is skipped and the
client's own key is forwarded verbatim — so the throttler still supplies AIMD,
fair queue, pacing and `/metrics`. Cost moves from plan-covered to metered;
that trade is the operator's call.

Either way, §2 should be resolved and §3 reconciled.
