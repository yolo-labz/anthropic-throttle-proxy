**Decided:** 19/10/2026 19:37 BRT by the queue-admission lead (pane w2P:p1H).
**Ruling:** Placement **A** (new role-aware OpenAI ingress, e.g. `:8776`) — but
**deferred: do not build it now.** No src change, no commit, spec stays a draft.

is therefore an *account* hold, not a zen-lane hold.

## Why A over B

1. **Protocol fork.** The `:8760` ingress is Anthropic-protocol only
   (`POST /v1/messages`); reusing it for the OpenAI-shape gates would be a
   protocol fork. A fork is worse than a new thin router, and the spec is right
   to refuse it. So B has no cheaper cousin to fall back on.
2. **Coupling.** B puts cross-gate routing inside the exact hot path this lead
   is reworking (proxy.py/limiter.py admission). Two risk surfaces on one
   function is how a queue bug becomes a routing bug. A keeps each gate proxy a
   clean, single-semaphore queue — the SPOF-fallback property is the one worth
   keeping.
3. **Opt-in granularity.** Spillover is per-family; B's in-data-plane placement
   makes a per-family decision awkward. That is the spec's own argument and it
   stands.

## Why it stays deferred (the report did not make this argument)

**Spillover cannot help in the incident class it exists for.** R1 restricts it
to exactly one model id (`longcat-2.5-preview-free`, the only free family on
both gates) — everything else is single-gate by construction. And the receipt
above shows go and zen share the upstream account `e574f38a`, so when go is
saturated by *account* pushback, zen is held by the same account hold and R3's
pre-flight (`retry_after_until <= now`) refuses the spill. The router would be
a third hop, a new SPOF and a new deployment for a policy that fires almost
never.

**Trigger to actually build it** (all three, evidenced):
1. a go saturation during which zen is *measured* free of the shared hold, AND
2. real `longcat-*` traffic volume that a spill would have saved, AND
3. the queue-admission rework (this lead's slice) is merged and stable — so the
   spill path lands on a settled hot path.

Until then: **R1–R3 + G1–G10 stay as a pure policy module and guard tests,
default OFF**, exactly as the slice delivered them.
