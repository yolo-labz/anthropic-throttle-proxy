How to read this view

Accounted tokens add fresh input, cache write, cache read and output. Reasoning is already inside output.

Recorded calls count usage-bearing source records. They do not establish unique tasks or physical API attempts.

Filters select source rows across this whole window. Pane labels are source attribution, not verified workspace ownership.

What this source cannot show

No quota denominator, account eligibility, request timeline or smaller time buckets is present in this aggregate.

This is observed usage coverage, not complete provider history, billed spend or live streaming speed. No reported exclusions does not prove complete coverage.
